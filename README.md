# คู่มือขึ้นเว็บบน Vercel (มือใหม่ทำตามได้เลย)

ทำผ่านเบราว์เซอร์ล้วนๆ ไม่ต้องลงโปรแกรมอะไรเพิ่ม ใช้เวลารวมประมาณ 15-20 นาที

สิ่งที่ต้องมีก่อนเริ่ม: ไฟล์ `order-tracker-app.zip` ที่ดาวน์โหลดไว้จากแชทก่อนหน้า (เช็คในโฟลเดอร์ Downloads ของเครื่อง)

---

## ขั้นที่ 0 — แตกไฟล์ zip

หาไฟล์ `order-tracker-app.zip` ที่ดาวน์โหลดมา แล้วดับเบิลคลิก (หรือคลิกขวา → Extract All / แตกไฟล์) จะได้โฟลเดอร์ชื่อ `order-tracker-app` ที่มีไฟล์ข้างในหลายไฟล์ — เก็บโฟลเดอร์นี้ไว้ จะใช้ในขั้นที่ 3

## ขั้นที่ 1 — สมัคร/ล็อกอิน GitHub

1. เปิดเบราว์เซอร์ ไปที่ **github.com**
2. ยังไม่มีบัญชี → กด **Sign up** มุมขวาบน กรอกอีเมล ตั้งรหัสผ่าน ตั้งชื่อผู้ใช้ ทำตามขั้นตอนจนจบ (จะมีอีเมลยืนยันส่งไปให้ กดยืนยันด้วย)
   มีบัญชีแล้ว → กด **Sign in** ล็อกอินได้เลย

## ขั้นที่ 2 — สร้าง repository ใหม่

1. มุมขวาบนของหน้า github.com มีไอคอน **+** กดแล้วเลือก **New repository**
2. ช่อง Repository name ใส่ชื่อ เช่น `order-tracker`
3. เลือก **Private** (กันคนอื่นเห็นโค้ด)
4. **ไม่ต้องติ๊กอะไรเพิ่ม** ปล่อย repo ให้ว่างเปล่าไว้
5. เลื่อนลงล่างสุด กดปุ่มสีเขียว **Create repository**

## ขั้นที่ 3 — อัปโหลดไฟล์ทั้งหมดขึ้น GitHub

1. หลังสร้าง repo เสร็จ จะเห็นข้อความพร้อมลิงก์ **uploading an existing file** — กดลิงก์นั้น
   (ถ้าไม่เจอ ให้หาปุ่ม **Add file** ด้านบนขวา → เลือก **Upload files**)
2. เปิดโฟลเดอร์ `order-tracker-app` ที่แตกไว้ในขั้นที่ 0 (เปิด File Explorer บน Windows หรือ Finder บน Mac)
3. เลือกไฟล์/โฟลเดอร์ **ทั้งหมด** ข้างในนั้น (กด Ctrl+A บน Windows หรือ Cmd+A บน Mac)
4. ลากไฟล์ที่เลือกทั้งหมดไปวางบนหน้าเว็บ GitHub ตรงกล่องที่เขียนว่า "Drag files here"
5. รอจนอัปโหลดครบ (เห็นรายชื่อไฟล์ทุกไฟล์ขึ้นมา)
6. เลื่อนลงล่างสุด ปล่อยข้อความ commit เป็นค่าเริ่มต้นก็ได้ กดปุ่มสีเขียว **Commit changes**

## ขั้นที่ 4 — สมัคร/ล็อกอิน Vercel

1. ไปที่ **vercel.com**
2. กด **Sign Up** แล้วเลือก **Continue with GitHub** (ง่ายสุด เชื่อมกับ GitHub ให้อัตโนมัติ)
3. ถ้าเด้งไปหน้า GitHub ให้กด **Authorize Vercel**

## ขั้นที่ 5 — Import โปรเจกต์เข้า Vercel

1. ในหน้า Vercel dashboard กดปุ่ม **Add New...** มุมขวาบน → เลือก **Project**
2. จะเห็นรายชื่อ repo จาก GitHub หา `order-tracker` แล้วกด **Import**
3. หน้าตั้งค่า ปล่อยทุกอย่างเป็นค่าเริ่มต้น (Vercel รู้จัก Next.js ให้เองอัตโนมัติ) กด **Deploy**
4. รอประมาณ 1-2 นาที เห็น log กำลังรันอยู่ พอเสร็จจะมีข้อความ "Congratulations" พร้อมลิงก์เว็บ เช่น `order-tracker-xxxx.vercel.app`

ตอนนี้เว็บขึ้นแล้ว แต่ **ยังบันทึกออเดอร์ไม่ได้** (รีเฟรชแล้วข้อมูลหาย) เพราะยังไม่มีฐานข้อมูลเชื่อมอยู่ ทำขั้นที่ 6 ต่อ

## ขั้นที่ 6 — เพิ่มฐานข้อมูล

1. จากหน้าโปรเจกต์บน Vercel หาแท็บเมนูด้านบน คลิก **Storage**
2. กด **Create Database** (หรือ **Browse Marketplace** ถ้าไม่เจอปุ่มแรก)
3. หา/เลือก **Upstash** (ประเภท Redis หรือ KV) — มีแพ็กเกจฟรีให้เลือกใช้
4. ตั้งชื่อฐานข้อมูล (ชื่ออะไรก็ได้) แล้วกด Create/Continue
5. ระบบจะถามว่าจะเชื่อมกับโปรเจกต์ไหน เลือก `order-tracker` แล้วกด **Connect**

## ขั้นที่ 7 — Deploy ซ้ำอีกครั้ง

ค่าฐานข้อมูลที่เพิ่งเชื่อมยังไม่มีผลกับเว็บที่ deploy ไปแล้วในขั้นที่ 5 ต้องสั่ง deploy ใหม่:

1. ไปแท็บ **Deployments** ของโปรเจกต์
2. deployment ล่าสุด (บนสุด) จะมีจุดสามจุด **⋯** ทางขวา กดแล้วเลือก **Redeploy**
3. ยืนยันอีกครั้งในหน้าต่างที่เด้งขึ้นมา รอจนเสร็จ

## ขั้นที่ 8 — ทดสอบว่าใช้งานได้จริง

1. เปิดลิงก์เว็บของเรา (`order-tracker-xxxx.vercel.app`)
2. ลองบันทึกออเดอร์สัก 1 รายการ
3. กด refresh หน้าเว็บ — ถ้าออเดอร์ที่บันทึกไว้ยังอยู่ แปลว่าสำเร็จ พร้อมใช้งานจริงแล้ว

## ถ้าติดปัญหา

- อัปโหลดเสร็จแล้วเว็บ error / ขึ้นหน้าขาว → ก็อปข้อความ error ที่เห็นมาบอกได้เลย จะช่วยดูให้
- ไฟล์อัปโหลดไม่ครบ/หลุดหาย → ลบ repo ทิ้งแล้วเริ่มใหม่ตั้งแต่ขั้นที่ 2 ได้ ไม่มีผลเสียอะไร
- หาปุ่มไม่เจอเพราะหน้าตาเว็บเปลี่ยนไปจากที่บอก → บอกได้ว่าเห็นอะไรอยู่ตรงหน้า จะช่วยไล่หาให้
